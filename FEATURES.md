# Main Dashboard

A private dashboard.

- Dark themed
- `font-family: "Helvetica Neue", Helvetica, FreeSans, Arial, sans-serif`

## Landing Page

- Horizontal `<nav>` menu for the Areas
- Columns for the Areas

## Areas

### Todo

- Kanbanboards
- 3 columns: todo, doing, done
- Tasks can only be added in todo. Doing and done have no 'add a task' fields;
  move existing tasks into those columns.
- single line entries
- each line can be reordered by draging
- each board can be reordered by draging
- on the landing page
  - each boards heading gets listed
  - below each heading the top doing is showing
  - if there is no doing then the top todo is showing
